# Timbum

A blocky free-for-all shooter made with Godot 4.7. Play against bots offline, or host a match and have friends join by IP.

## Features

- **Free-for-all deathmatch.** The first player to reach the kill limit wins, or whoever has the most kills when time runs out. After each match a results screen hands out coins and XP, then the next map in the rotation loads.
- **Bots.** Easy, Normal and Hard bots navigate with a navmesh. They strafe, aim-track, throw grenades and fall back to their knife. They also pick up health when hurt and ammo when low. Bots fill the empty slots, and one drops out each time a human joins.
- **Online play over IP.** Uses ENet on UDP port 7777 by default, with up to 12 players. The host's machine runs the match.
- **9 weapons.** Block 9 pistol, Cuber .44 revolver, Bit-SMG, AR-Cube rifle, Brick Buster shotgun, Stacker LMG, Voxel Longshot sniper with a scope, Boom Block rocket launcher, and the Pixel Blade knife. Every player also carries frag grenades.
- **Gunplay.** Aiming down sights, recoil, spread bloom, damage falloff, headshots, hitmarkers, kill feed, kill streaks and multi-kills.
- **5 maps.** Village, Desert Ruins, Factory, Sky Islands and Snow Fort. Each has its own sky, fog and lighting. Health, ammo and grenade pickups are spread around every map.
- **Shop and locker.** Coins buy guns, 11 weapon skins (including camo, lava, neon, gold, diamond and galaxy), 10 hats and 9 outfits. The locker is where you equip your loadout and look.
- **Progression.** XP, levels, a daily reward and lifetime stats.
- **Everything is generated by code.** Textures, models, sound effects and the chiptune music are all procedural, so the project contains no asset files.

## Controls

| Action | Key |
|---|---|
| Move | WASD / arrow keys |
| Jump / Sprint / Crouch | Space / Shift / Ctrl or C |
| Fire / Aim down sights | Left mouse / Right mouse |
| Reload | R |
| Primary / Secondary / Knife | 1 / 2 / 3 or mouse wheel, Q swaps to the last weapon |
| Grenade | G |
| Quick melee | V or F |
| Scoreboard | Tab (hold) |
| Chat | T or Enter |
| Pause / settings | Esc |

## Playing online

1. **Host:** choose **Host Game**, pick your map and settings, then press Start. The host screen shows your LAN IP addresses.
2. **Join:** choose **Join Game**, enter the host's IP and port (default 7777), then press Join.

On the same Wi-Fi or LAN, use the LAN address the host screen shows. Over the internet, the host has to forward UDP port 7777 on their router to their computer and share their public IP. The host's firewall must also allow Timbum.

## Running from source

1. Install [Godot 4.7](https://godotengine.org/download).
2. Open `project.godot`, or run `godot --path .`

## Building release versions

You need the Godot 4.7 export templates installed. Run:

```sh
godot --headless --path . --export-release "macOS"   build/macos/Timbum.zip
godot --headless --path . --export-release "Windows" build/windows/Timbum.exe
godot --headless --path . --export-release "Linux"   build/linux/Timbum.x86_64
```

The macOS build is signed ad hoc and not notarized. The first time, open it with right-click → Open.

## Project layout

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for module contracts, the networking model and collision layers.

Your save file (coins, items, settings) is stored at `user://profile.json`. Its location depends on your OS:

| OS | Save folder |
|---|---|
| macOS | `~/Library/Application Support/Godot/app_userdata/Timbum/` |
| Windows | `%APPDATA%\Godot\app_userdata\Timbum\` |
| Linux | `~/.local/share/godot/app_userdata/Timbum/` |
